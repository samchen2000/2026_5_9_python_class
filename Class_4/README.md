### 上課內容 :  
1. Python 提供四種主要的內建資料結構，每種都有其特定的用途和特性：
 **List (列表): 有序、可變的資料集合**
 **Tuple (元組): 有序、不可變的資料集合**
 **## Dictionary (字典): 鍵值對的無序集合**
 **Set (集合): 無序、不重複元素的集合**

2. 資料結構比較表
 特性 | List | Tuple | Dictionary | Set |
|------|------|-------|------------|-----|
| 語法 | `[]` | `()` | `{}` | `set()` 或 `{}` |
| 可變性 | 可變 | 不可變 | 可變 | 可變 |
| 有序性 | 有序 | 有序 | 無序 (Python 3.7+保持插入順序) | 無序 |
| 重複元素 | 允許 | 允許 | Key不允許 | 不允許 |
| 索引存取 | 支援 | 支援 | 不支援 | 不支援 |
